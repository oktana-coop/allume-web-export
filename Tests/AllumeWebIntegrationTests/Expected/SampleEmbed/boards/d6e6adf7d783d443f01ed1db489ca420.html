A paradigm is a style of programming. Most languages mix several: Haskell is functional, OCaml adds objects, and Prolog is built on logic.

Functional programming

Functions are values, and programs are built by combining them.

Pure functions

Same input, same output, no side effects.

Laziness

Evaluate only what is needed.
